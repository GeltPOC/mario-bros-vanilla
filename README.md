# Gabriel Bros

Juego Mario Bros Vanilla con Next.js.

## Cambios
- Título del juego actualizado a **"Gabriel Bros"**

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
npm start
```

El proyecto se sirve en: `https://gelt-code.com/mario-bros-vanilla`
