# mario-bros-vanilla

A Next.js project.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production

Build and start:

```bash
npm run build
npm start
```

Or using PM2:

```bash
pm2 start ecosystem.config.js
```
